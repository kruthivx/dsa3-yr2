# High-Performance Text Searching Application

A text searching application developed using the **KMP (Knuth–Morris–Pratt) algorithm** to efficiently find patterns in large text files.

## Features

* Searches for a given pattern and finds all its occurrences in text.
* Uses the KMP algorithm for fast and efficient searching.
* Uses a Prefix/Failure Table to reduce unnecessary comparisons.
* Supports searching across multiple text files.
* Displays the positions where the pattern is found.
* Provides visualization of matching positions and search results.
* Compares the performance of different string-searching algorithms.
* Explores algorithms such as Z-Function, Rabin-Karp, Dynamic Programming, and Network Flow.
* Designed to handle large text datasets efficiently.

## Objective

The main objective of this project is to provide a fast and efficient method for searching patterns in large text datasets while demonstrating and comparing different algorithmic approaches.
